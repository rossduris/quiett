# Quiett brand kit — locked 2026-09-19

## Mark
**A — Q monogram:** geometric Q with a horizontal stillness-line tail. App icon, favicon, social avatar.

## Spelling
**Quiett** (two t’s) in product titles. `quiett` lowercase for domain / slug / scheme (`quiett.app`, `com.rossduris.quiett`). Never “Quiet” (one t).

## Voice line (lander / marketing)
**Wake. Meditate. Begin.**

Product one-liner: An alarm that won’t fully let go until you sit upright and still for 3 minutes — then it turns into a short morning meditation.

Inter / Geist. Calm but firm — clear hierarchy, no soft spa script fonts.
